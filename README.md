# gestor-estudiantes

Aplicación de escritorio en Python (Tkinter) para gestionar estudiantes:
guardar, buscar, eliminar e imprimir, con datos guardados en un archivo JSON.

## Requisitos
- Python 3.10 o superior (tkinter viene incluido)

## Instalación y ejecución
1. Clonar el repositorio.
2. Instalar la dependencia: `pip install -r requirements.txt`
3. Ejecutar desde la carpeta del proyecto: `python main.py`

## Funciones
- Guardar, buscar y eliminar estudiantes (con validación de datos)
- Imprimir la lista en un archivo de texto
- Mejoras opcionales: tabla de estudiantes, botón Limpiar, confirmación al eliminar,
  exportar a PDF eligiendo la ubicación, icono propio
